    About Clean Paste

    Clean Paste turns content copied from Word, Google Docs or a web page into clean, minimal HTML that's ready for any CMS. It strips the hidden styles, fonts and leftover code that come along when you paste, keeps the real structure (headings, lists, links, tables, bold and italic), and points out anything worth fixing before you publish. It runs entirely in your browser: nothing you paste is uploaded or saved.

    How to use it

    1. Copy your content from Word, Google Docs, a web page or an HTML file, and press Ctrl + V anywhere on the page.
    2. Read the checks on the left. Click Show on any check to jump to the line it means.
    3. Fix things in the Text tab with the toolbar (headings, lists, links, remove all bold), or edit the code in the HTML tab.
    4. Copy the result: formatted for visual editors like Shopify, Squarespace and Wix, HTML for code views, plain text, or WordPress blocks for the block editor.

    What it cleans up

    • Inline styles, fonts, spans, classes and Word's hidden markup and comments.
    • Word's fake bullet and number paragraphs, rebuilt as real nested lists.
    • Google Docs redirect links, changed back to the real address, and links starting with www. given https://.
    • Images, marked as [Image] placeholders so you know where to upload them in the CMS.

    What it checks

    • An H1 in the body (most CMSs already use the title as the H1) and skipped heading levels.
    • Lines that are only bold text and were probably meant as headings.
    • Links to drafts, file shares or local files, Word bookmark links, links that go nowhere, "click here" link text, the same page linked more than once, and http:// links.
    • Paragraphs over 150 words. It also shows the word count and reading time.
