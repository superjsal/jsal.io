Drupal SEO: What you can change, and where

For large, complex or multilingual sites in government and enterprise. Here’s what you can change for search on Drupal, and where each setting is. Every answer is checked against Drupal’s own help docs.

SEO on Drupal

What people ask most often, with the menu path to each setting.

Change the title and description in Google

Plugin/appYes, with the Metatag module
Where

Edit the content→, thenMeta tags (defaults: Configuration→, thenSearch and metadata→, thenMetatag)

Drupal’s help page ↗ (opens in a new tab)

Choose page addresses (URLs)

Built inURL aliases (the Pathauto module adds patterns)
Where

Configuration→, thenSearch and metadata→, thenURL aliases (Pathauto adds a Patterns tab)

Drupal’s help page ↗ (opens in a new tab)

Redirect old links (301s)

Plugin/appYes, with the Redirect module
Where

With the Redirect module:Configuration→, thenSearch and metadata→, thenURL redirects→, thenAdd redirect

Drupal’s help page ↗ (opens in a new tab)

Add structured data (schema)

Plugin/app
Where

Edit the content→, thenMeta tags (with the Schema.org Metatag module)

Drupal’s help page ↗ (opens in a new tab)

Hide a page from search (noindex)

Plugin/appWith the Metatag module
Where

Edit the content→, thenMeta tags→, thenAdvanced→, thenRobots

Drupal’s help page ↗ (opens in a new tab)

Block AI crawlers

Plugin/appWith the RobotsTxt module, or by editing the robots.txt file on the server
Where

The RobotsTxt module’s settings, or the robots.txt file in the site’s root folder
